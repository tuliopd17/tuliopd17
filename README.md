## 🚀 Projetos em destaque

### ♟️ [Chess Review](https://github.com/tuliopd17/chess-review) — [chessreview.com.br](https://chessreview.com.br)
Análise gratuita de partidas de xadrez inspirada no Game Review do chess.com, no ar em produção. O **Stockfish roda direto no navegador (WebAssembly + Web Workers)**, classificando lances, calculando acurácia e permitindo explorar variantes ao vivo.<br/>
`Python` `FastAPI` `JavaScript` `Stockfish WASM` `Docker` `Google Cloud Run`

### 📦 [Sistema de Processamento de Pedidos — Microsserviços](https://github.com/tuliopd17/order-processing-system-microservices)
Arquitetura de microsserviços orientada a eventos (pedidos, estoque e notificações) com comunicação assíncrona via RabbitMQ e banco de dados por serviço.<br/>
`Java 17` `Spring Boot` `Spring AMQP` `RabbitMQ` `PostgreSQL` `Docker Compose`

### 🔗 [Encurtador de URLs](https://github.com/tuliopd17/url-shortener-in-java)
API de encurtamento de URLs com cache em Redis seguindo o padrão **Cache Aside** para alta performance de leitura.<br/>
`Java 21` `Spring Boot 3` `PostgreSQL` `Redis` `Docker Compose`
